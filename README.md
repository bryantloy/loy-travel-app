# Loy Travel v0.3 — Photo Review Build

This review build prioritizes the Explore experience.

- Restores a prominent Loy Travel logo block on Home.
- Converts all 24 Explore ideas to photo-first cards.
- Uses credited public-domain / Creative Commons Maui photos for key exact locations.
- Uses custom Loy family concept images for surf, snorkeling, zipline and food ideas.
- Keeps Supabase profiles, shared voting, packing, feedback, itinerary and CSV export.
- `/api/config.js` remains required for Vercel.
