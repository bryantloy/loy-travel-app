LOY TRAVEL v0.13.1 — CARD CATALOG INTEGRATION

UPLOAD THESE FILES/FOLDERS TO THE ROOT OF THE TEST BRANCH:
- app.js
- styles.css
- card-catalog.json
- cards.json  (compatibility mirror; safe to replace old file)
- assets/cards/  (all 74 WEBP card assets)

NO SQL REQUIRED.
NO SUPABASE DATA IS RESET.

WHAT CHANGED
- App loads /card-catalog.json as the source of truth.
- All 74 cataloged cards are included.
- Existing starter-pack IDs remain unchanged.
- Card filters now use owner + rarity + series metadata.
- Series filter is data-driven from JSON.
- Card modal shows rarity, series, and owner.
- Falls back to /cards.json if card-catalog.json cannot load.

ASSET STRUCTURE
/assets/cards/<stable-card-id>.webp

FUTURE RULE
Create new card artwork directly as WEBP, add it to /assets/cards/, then add one metadata record to card-catalog.json.
